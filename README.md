# 📊 AdventureWorks Sales Analysis Dashboard

An interactive **Sales Analysis Dashboard built in Microsoft Excel** using the AdventureWorks sample dataset.

## 🎯 Project Overview

This project transforms raw sales data into an interactive dashboard to analyze:

- Revenue, COGS & Profit
- Monthly, Quarterly & Year-over-Year performance
- Top Products & Customers
- Customer demographics
- Country-wise performance
- Product pricing & availability

## 🛠️ Tools & Techniques

**Power Query + Data Transformation + Power Pivot + Data Modeling + DAX + PivotTables + PivotCharts + Advanced Excel Formulas + Time-Series Analysis + Product & Customer Analysis + Dynamic Visualizations + Slicers + VBA/Macros + Dashboard Navigation**

## ⚡ Key Features

- Interactive Year, Month & Country slicers
- Dynamic KPI cards and charts
- Top 5 Product & Customer analysis
- Year-over-Year analysis
- Dynamic business insights
- Custom geographic visualization
- VBA-powered Clear Filter button
- Dashboard navigation
